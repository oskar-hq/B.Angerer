# Angerer Consulting

Statische Website für Bettina Angerer (Angerer Consulting, Bayreuth). Kein Build nötig.

## Lokal ansehen

    python3 -m http.server 8000

## GitHub Pages (Testphase)

Settings > Pages > Source: "Deploy from a branch", Branch auswählen, Ordner `/ (root)`.

## Vor dem Livegang

- `noindex` in den HTML-Dateien entfernen
- Platzhalter in `impressum.html` und `datenschutz.html` füllen
- Empfängeradresse `CONTACT_EMAIL` (Testphase) in `assets/js/main.js` ändern
- Portrait und Referenzen prüfen
